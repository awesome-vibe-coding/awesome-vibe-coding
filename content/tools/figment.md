Figment's signed-in AI website editor works on a separate static copy of an
existing public website. It does not change the original website-builder project.

## Workflow

- Import a public website you own or have permission to copy and inspect the
  private preview.
- Request a managed AI edit, or exchange selected existing HTML/CSS files with
  your own AI and return the edits manually as JSON.
- Review the saved version before approving publication to a separate URL.

## Limits

Forms, account login, checkout, and backend behavior do not transfer with a static
copy. The Own AI file exchange is not an automatic chat connection and does not
add arbitrary files. Import and preview require no card. Managed AI edits are
paid; the Own AI path has no Figment AI-credit charge, but provider and service
limits still apply.

## Good for

Website owners who want bounded AI-assisted changes to an imported static page,
with a preview and an explicit publication decision.
