anti-slop-design is an autonomous Principal Design Technologist agent skill. It prevents coding agents from producing repetitive AI design tropes (generic purple gradients, unstyled 3-card marketing grids, and emoji buttons) by enforcing strict design token archetypes and tactile micro-states.

## Why a skill for this

AI coding assistants frequently default to generic, uninspired layouts and superficial styling clichés when building frontends. anti-slop-design acts as a design quality gate, constraining agents to cohesive typography, deliberate spacing rhythm, and complete interactive state responsiveness before shipping.

## Good for

Vibe coding landing pages, SaaS dashboards, and web applications where clean, human-grade design craft is required.
