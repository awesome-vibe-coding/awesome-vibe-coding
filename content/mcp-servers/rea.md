REA exposes the same inspection workflows through a CLI and an MCP server. Agents can examine native binaries, JavaScript and Electron bundles, and .NET assemblies. Results include supporting evidence and analysis limits. Deep native analysis can use an existing Ghidra, Hopper, or IDA installation.

## Good for

Investigating how a shipped app implements a behavior when its source code is unavailable.
